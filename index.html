チャンネルについて

午前2時。家のみんなが寝静まったキッチンで、電子レンジや冷蔵庫が、自分の中で何が起きているのかをこっそり語りはじめる——。「真夜中ラジオ_物の仕組み」は、身の回りのモノの仕組みを、深夜ラジオの語り口と、物理的に正しく動く図解アニメーションで解説する YouTube チャンネルです。

ナレーションには AI 音声（Google Gemini）を、図解アニメーションにはプログラム（Manim / Remotion）を使っています。内容は出典をもとに確認し、各動画の概要欄に参考文献を載せています。

投稿ツール（Midnight Radio Uploader）について

このチャンネルの運営者が、自分の YouTube チャンネルへ動画を投稿するために使う、個人用のツールです。運営者のパソコン上でのみ動作し、一般には公開・配布していません。

このツールは YouTube API サービスを利用しています。Google アカウントで許可を受けたうえで、次の操作だけを行います。

  • 動画のアップロードと、タイトル・概要欄などの設定
  • サムネイル画像と字幕の設定
  • 投稿先チャンネルの名前と ID の確認

データの扱いについては プライバシーポリシー をご覧ください。

English

Midnight Radio: How Things Work is a YouTube channel in which everyday objects—a microwave oven, a refrigerator—explain how they work, in the style of a late-night radio show, with physically accurate animated diagrams. Narration uses AI-generated speech (Google Gemini), and each video lists its sources in the description.

Midnight Radio Uploader is a personal tool used only by the channel owner to upload videos to the owner's own YouTube channel. It runs locally on the owner's computer and is not distributed to the public. This tool uses YouTube API Services. With the permission granted through the owner's Google account, it only uploads videos, sets their metadata, thumbnails and captions, and reads the channel name and ID to confirm the upload destination. See the Privacy Policy for details.
