チャンネルについて

「放課後の視聴覚室」は、平成のはじめに学校で見た教材ビデオのような雰囲気で、生成 AI や自動運転などの新しい技術の仕組みを解説する YouTube チャンネルです。ナレーションには AI 音声を、図解アニメーションにはプログラムを使っています。内容は出典をもとに確認し、各動画の概要欄に参考文献を載せています。

投稿ツール（houkago-shichokakushitsu）について

このチャンネルの運営者が、自分の YouTube チャンネルへ動画を投稿するための個人用ツールです。運営者のパソコン上でのみ動作し、一般には公開・配布していません。

このツールは YouTube API サービスを利用しています。Google アカウントで許可を受けたうえで、次の操作だけを行います。

  • 動画の非公開でのアップロードと、タイトル・概要欄などの設定
  • サムネイル画像の設定
  • 投稿先チャンネルの名前と ID の確認

データの扱いについては プライバシーポリシー をご覧ください。

English

Houkago no Shichokakushitsu ("After-School AV Room") is a YouTube channel that explains how new technologies such as generative AI and self-driving cars work, in the style of an early-1990s Japanese classroom video. Narration uses AI-generated speech, diagrams are animated programmatically, and each video lists its sources in the description.

The upload tool (houkago-shichokakushitsu) is a personal tool used only by the channel owner to upload videos to the owner's own YouTube channel. It runs locally on the owner's computer and is not distributed to the public. This tool uses YouTube API Services. With the permission granted through the owner's Google account, it only uploads videos as private, sets their metadata and thumbnails, and reads the channel name and ID to confirm the upload destination. See the Privacy Policy for details.
