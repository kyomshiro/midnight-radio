プライバシーポリシー

Midnight Radio Comments ／ 制定日：2026年10月10日

本ポリシーは、YouTube チャンネル「真夜中ラジオ_物の仕組み」の運営者（以下「運営者」）が使用するコメント投稿ツール「Midnight Radio Comments」（以下「本ツール」）における、利用者情報の取り扱いを定めるものです。

1. YouTube API サービスの利用

本ツールは YouTube API サービスを利用しています。本ツールを利用することにより、利用者は YouTube 利用規約 に拘束されることに同意したものとみなされます。また、Google による情報の取り扱いについては Google プライバシーポリシー をご確認ください。

2. 利用者

本ツールは、運営者が自分の YouTube チャンネルの動画にコメントを投稿するためだけに使用する個人用ツールであり、運営者以外の第三者には提供していません。

3. アクセス・取得する情報

本ツールは、運営者の Google アカウントでの許可（OAuth 2.0）にもとづき、youtube.force-ssl の権限で YouTube API にアクセスし、次の操作だけを行います。

  • 投稿先チャンネルの名前と ID の確認（読み取りのみ）
  • 運営者自身の動画の公開状態の確認（読み取りのみ）
  • 運営者自身の動画への、運営者が用意したコメントの投稿

この権限では他の操作も可能ですが、本ツールは上記以外の操作を行いません。視聴者のコメント、視聴履歴、登録者の情報は読み取らず、コメントや動画の編集・削除も行いません。

本ツールが保存する情報は次のとおりです。

  • 認証情報（アクセストークン・リフレッシュトークン）：運営者のパソコン内のファイルと、運営者の非公開の GitHub リポジトリの暗号化されたシークレット（GitHub Actions Secrets）に保存します。
  • 投稿記録（動画の ID、コメントの本文、投稿したコメントの ID と日時）：運営者のパソコン内のファイルと、運営者の非公開の GitHub リポジトリに保存します。
  • チャンネル名とチャンネル ID：投稿先の確認に使うだけで、保存しません。

4. 情報の利用目的

取得した情報は、運営者の動画へのコメントの投稿のためにのみ使用します。広告、分析、プロファイリングなどの目的には使用しません。

5. 情報の共有・第三者提供

本ツールは、運営者のパソコン上と、運営者の非公開リポジトリの GitHub Actions（GitHub 社が提供する実行環境）上で動作します。情報は Google（YouTube）と、この実行・保存のために GitHub 社が扱う範囲を除き、第三者に送信・共有・販売することはありません。

6. 保存期間と削除

認証情報は、運営者がアクセス権を取り消すか、保存ファイルとシークレットを削除するまで保存されます。投稿記録は運営者がいつでも削除できます。

7. アクセス権の取り消し

本ツールに付与したデータへのアクセス権は、Google のセキュリティ設定ページ からいつでも取り消すことができます。また、本ツールの revoke コマンドでも、Google 側の許可の取り消しと、パソコン内に保存した認証情報の削除を一度に行えます。

8. お問い合わせ

本ポリシーおよび本ツールに関するご質問・ご意見は、GitHub Issues からお寄せください。

9. 改定

本ポリシーを改定する場合は、このページで改定内容と改定日をお知らせします。

Privacy Policy

Midnight Radio Comments / Effective date: October 10, 2026

This policy describes how "Midnight Radio Comments" (the "Tool"), used by the owner of the YouTube channel "Midnight Radio: How Things Work" (the "Owner"), handles user information.

1. Use of YouTube API Services

The Tool uses YouTube API Services. By using the Tool, users agree to be bound by the YouTube Terms of Service. Please also see the Google Privacy Policy.

2. Users

The Tool is a personal tool used only by the Owner to post comments on the Owner's own YouTube videos. It is not provided to anyone else.

3. Information accessed and collected

Based on authorization granted through the Owner's Google account (OAuth 2.0), the Tool accesses the YouTube API with the youtube.force-ssl scope and performs only these operations: reading the channel name and ID to confirm the destination, reading the privacy status of the Owner's own videos, and posting comments prepared by the Owner on those videos. Although the scope allows more, the Tool does nothing else. It does not read viewers' comments, watch history or subscriber information, and does not edit or delete any comments or videos.

  • Authorization tokens are stored in a file on the Owner's computer and as encrypted secrets (GitHub Actions Secrets) in the Owner's private GitHub repository.
  • Posting records (video IDs, comment text, IDs and times of posted comments) are stored on the Owner's computer and in the Owner's private GitHub repository.
  • The channel name and channel ID are used to confirm the destination and are not stored.

4. How information is used

Information is used solely to post comments on the Owner's videos. It is not used for advertising, analytics or profiling.

5. Sharing

The Tool runs on the Owner's computer and on GitHub Actions (an execution environment provided by GitHub) in the Owner's private repository. Information is not sent, shared or sold to any third party, except Google (YouTube) and GitHub to the extent needed to run the Tool and store its data.

6. Retention and deletion

Authorization tokens are kept until access is revoked or the files and secrets are deleted. Posting records can be deleted by the Owner at any time.

7. Revoking access

Access granted to the Tool can be revoked at any time via the Google security settings page. The Tool's revoke command also revokes the authorization with Google and deletes the locally stored tokens in one step.

8. Contact

Questions or complaints about this policy or the Tool can be submitted via GitHub Issues.

9. Changes

Any changes to this policy will be posted on this page with the revised effective date.
