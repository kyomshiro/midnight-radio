Midnight Radio Comments

コメント投稿ツール

プライバシーポリシー / Privacy Policy 利用規約 / Terms of Service

YouTube チャンネル「真夜中ラジオ_物の仕組み」の運営者が、自分のチャンネルの動画に、自分のチャンネルの名前でコメントを投稿するための個人用ツールです。運営者以外には公開・配布していません。

このツールは YouTube API サービスを利用しています。Google アカウントで許可を受けたうえで、次の操作だけを行います。

  • 投稿先チャンネルの名前と ID の確認
  • 自分の動画の公開状態の確認（公開されたかどうか）
  • 自分の動画への、運営者が用意したコメントの投稿

視聴者のコメントを読んだり、削除・編集したりすることはありません。動画のアップロードには、別のツール（Midnight Radio Uploader）を使っています。

データの扱いについては プライバシーポリシー をご覧ください。

English

Midnight Radio Comments is a personal tool used only by the owner of the YouTube channel "Midnight Radio: How Things Work" to post comments, as the channel, on the owner's own videos. It is not provided or distributed to anyone else. This tool uses YouTube API Services. With the permission granted through the owner's Google account, it only reads the channel name and ID, checks whether the owner's videos have been published, and posts comments prepared by the owner on those videos. It does not read, edit or delete viewers' comments. See the Privacy Policy for details.
