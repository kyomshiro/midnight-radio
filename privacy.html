プライバシーポリシー

Midnight Radio Uploader ／ 制定日：2026年10月4日（同日改定：利用する権限を縮小）

本ポリシーは、YouTube チャンネル「真夜中ラジオ_物の仕組み」の運営者（以下「運営者」）が使用する投稿ツール「Midnight Radio Uploader」（以下「本ツール」）における、利用者情報の取り扱いを定めるものです。

1. YouTube API サービスの利用

本ツールは YouTube API サービスを利用しています。本ツールを利用することにより、利用者は YouTube 利用規約 に拘束されることに同意したものとみなされます。また、Google による情報の取り扱いについては Google プライバシーポリシー をご確認ください。

2. 利用者

本ツールは運営者が自分の YouTube チャンネルに動画を投稿するためだけに使用する個人用ツールであり、運営者以外の第三者には提供していません。

3. アクセス・取得する情報

本ツールは、運営者の Google アカウントでの許可（OAuth 2.0）にもとづき、次の範囲でのみ YouTube API にアクセスします。

  • youtube.upload：動画とサムネイル画像のアップロード
  • youtube.readonly：投稿先チャンネルの名前と ID の確認（読み取りのみ）

本ツールが取得・保存する情報は次のとおりです。

  • 認証情報（アクセストークン・リフレッシュトークン）：運営者のパソコン内のファイルにのみ保存します。
  • アップロードした動画の ID：投稿記録として運営者のパソコン内のファイルに保存します。
  • チャンネル名とチャンネル ID：投稿先の確認のために画面に表示するだけで、保存しません。

視聴者のコメント、視聴履歴、登録者の情報など、上記以外の YouTube のデータにはアクセスしません。

4. 情報の利用目的

取得した情報は、運営者の YouTube チャンネルへの動画の投稿と、その設定のためにのみ使用します。広告、分析、プロファイリングなどの目的には使用しません。

5. 情報の共有・第三者提供

本ツールはサーバーを持たず、運営者のパソコン上でのみ動作します。取得した情報を、Google（YouTube）以外の第三者に送信・共有・販売することはありません。

6. 保存期間と削除

認証情報は、運営者がアクセス権を取り消すか、保存ファイルを削除するまで、運営者のパソコン内に保存されます。投稿記録は運営者がいつでも削除できます。

7. アクセス権の取り消し

本ツールに付与したデータへのアクセス権は、Google のセキュリティ設定ページ からいつでも取り消すことができます。また、本ツールの revoke コマンドでも、Google 側の許可の取り消しと、パソコン内に保存した認証情報の削除を一度に行えます。

8. お問い合わせ

本ポリシーおよび本ツールに関するご質問・ご意見は、GitHub Issues からお寄せください。

9. 改定

本ポリシーを改定する場合は、このページで改定内容と改定日をお知らせします。

Privacy Policy

Midnight Radio Uploader / Effective date: October 4, 2026 (revised the same day: reduced scopes)

This policy describes how "Midnight Radio Uploader" (the "Tool"), used by the owner of the YouTube channel "Midnight Radio: How Things Work" (the "Owner"), handles user information.

1. Use of YouTube API Services

The Tool uses YouTube API Services. By using the Tool, users agree to be bound by the YouTube Terms of Service. Please also see the Google Privacy Policy.

2. Users

The Tool is a personal tool used only by the Owner to upload videos to the Owner's own YouTube channel. It is not provided to anyone else.

3. Information accessed and collected

Based on authorization granted through the Owner's Google account (OAuth 2.0), the Tool accesses the YouTube API only with the scopes youtube.upload (uploading videos and thumbnails) and youtube.readonly (reading the channel name and ID to confirm the upload destination; read-only).

  • Authorization tokens are stored only in a file on the Owner's computer.
  • IDs of uploaded videos are stored as an upload record in a file on the Owner's computer.
  • The channel name and channel ID are displayed to confirm the destination and are not stored.

The Tool does not access any other YouTube data, such as viewer comments, watch history or subscriber information.

4. How information is used

Information is used solely to upload videos to the Owner's YouTube channel and configure them. It is not used for advertising, analytics or profiling.

5. Sharing

The Tool has no server and runs only on the Owner's computer. Information is not sent, shared or sold to any third party other than Google (YouTube).

6. Retention and deletion

Authorization tokens are kept on the Owner's computer until access is revoked or the file is deleted. Upload records can be deleted by the Owner at any time.

7. Revoking access

Access granted to the Tool can be revoked at any time via the Google security settings page. The Tool's revoke command also revokes the authorization with Google and deletes the locally stored tokens in one step.

8. Contact

Questions or complaints about this policy or the Tool can be submitted via GitHub Issues.

9. Changes

Any changes to this policy will be posted on this page with the revised effective date.
